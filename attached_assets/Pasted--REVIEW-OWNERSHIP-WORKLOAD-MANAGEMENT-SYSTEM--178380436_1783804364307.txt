====================================================
REVIEW OWNERSHIP & WORKLOAD MANAGEMENT SYSTEM
====================================================

Build a centralized Review Ownership and Workload Management system.

The purpose of this system is to ensure:

- Every review has a clear owner
- Managers can monitor workload
- Specialists know their queue
- Duplicate work is prevented
- Team capacity is visible
- Assignment status is visible throughout the application
- All review ownership changes are tracked

====================================================
SUCCESS CRITERIA
====================================================

Managers should immediately know:

- Who owns each review
- How many reviews each person has
- Which reviews are overdue
- Which specialists are overloaded
- Which specialists are underutilized

Specialists should immediately know:

- What is assigned to them
- What is due next
- What is highest priority
- What reviews are waiting for action

Assignment information must be visible everywhere a package review appears.

There should never be ambiguity about who is responsible for a review.
